# Lab 7 — Usability checklist (tick before your user test)

- [v] The first screen says what the assistant can do, with example questions
- [v] Empty or too-long input shows a friendly message (not a crash)
- [v] While waiting, the user sees "Thinking…"
- [v] Every answer from documents shows its sources
- [v] "I don't know" answers tell the user who can help (escalation)
- [v] If the backend is down, the page says so clearly
- [v] Each answer has 👍 / 👎, and clicking gives a "thanks" message
- [v] The page says it is an AI assistant
- [v] Text is readable (size, contrast); buttons have clear labels
- [v] Works on a phone-width window
